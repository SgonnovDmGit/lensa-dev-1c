# Линза: Разработчик 1С

Программа для Windows, в которой нейросеть работает **оператором конфигуратора 1С**: видит открытые
окна, читает модули, правит код и проверяет его штатной проверкой платформы — не копипастой через
чат, а сама, в вашем Конфигураторе.

[English version](README.en.md)

## Что умеет

- **Читает и правит код в открытом модуле.** Большой модуль на тысячи строк нейросеть читает по
  процедурам и областям, правит точечно, а изменения отмечаются маркерами.
- **Проверяет модуль платформой.** Запускает штатную проверку модуля, читает панель «Сообщения» и
  исправляет найденную ошибку. Об успехе говорит, только когда платформа это подтвердила.
- **Находит объекты конфигурации.** «Какие реквизиты у справочника Контрагенты? Открой его модуль
  объекта» — нейросеть найдет объект, назовет реквизиты и откроет модуль.
- **Песочница с редактором кода.** Подсветка 1С, свертка областей, модуль с диска или из EDT — без
  запущенного конфигуратора. Готовый код переносится в окно конфигуратора одной кнопкой.
- **Доска задач.** Нейросеть планирует работу на доске, вы правите план руками, он переживает
  перезапуск.
- **Видно, сколько стоит работа.** Метрики каждого хода и расход диалога по нейросетям.

## Требования

| | |
|---|---|
| Система | Windows 10 или 11, x64 |
| 1С | Конфигуратор 1С:Предприятие 8.3 или 8.5 — для работы с конфигурацией; песочница работает и без него |
| Сеть | Нужна: нейросети подключены через сервис «Линза» |

## Как начать

1. Скачайте ZIP из [Releases](../../releases/latest) и распакуйте. Внутри один файл `LenSaDev1C.exe` —
   устанавливать ничего не нужно, движок редактора уже внутри.
2. Запустите `LenSaDev1C.exe` и введите ключ доступа к сервису «Линза». Ключ выдается в личном
   кабинете на [lensacode.ai/developer](https://lensacode.ai/developer?utm_source=github_developer&utm_medium=repo&utm_campaign=gh-developer-readme).
3. Откройте Конфигуратор с нужной базой — программа найдет его сама.

Перед первой работой на рабочей базе сделайте копию: нейросеть умеет править код.
