# Планируется

## Ближайшее

- **Подключение через прокси.** Использовать системные настройки, отключить системный прокси или задать собственный.
- **Настройки по разделам.** Вкладки слева вместо растущего списка параметров.

## Следом

- **Использовать уже видимый объект.** Убрать ненужный поиск, когда нужная строка уже доступна, и разобраться с непостоянным применением поиска в оставшихся ветках.
- **Продолжение с нужного шага.** Атомарные клиентские действия для серверного workflow: использовать известный результат предыдущего шага, не повторять открытие и не перечитывать модуль после успешного сохранения.
- **Оставшиеся варианты расширений.** Полная матрица источников, свойств и типов реквизитов, включая незавершенный маршрут выбора реквизита.

## Дальше

- **Команды расширений для нейросети.** Выбор источника, действия с расширением и результаты проверок в чате после обновления сервера.
- **Полный цикл без вашего участия.** Нейросеть правит модуль, проверяет его платформой, читает панель «Сообщения», исправляет ошибки и сохраняет модуль.
- **Нейросеть знает, где вы работаете.** Видит процедуру под курсором, ведет песочницу своей базы и помнит планы из других диалогов по этой базе.
- **Нужная часть конфигурации на виду.** Поиск объектов по шаблону, состав и свойства реквизитов и табличных частей, формы; модуль объекта, менеджера или формы открывается по адресу.
- **Создание метаданных и работа в расширениях.** Нейросеть создает реквизиты, табличные части, объекты и формы и делает то же в расширении конфигурации — например, расширение, которое запрещает отгрузку при просроченной задолженности. Ставит точки останова и запускает отладку.
- **Возможности Консоли запросов и Ассистента 1С.** Метаданные живой базы, запросы, данные, журнал регистрации, СКД, сборка внешних отчетов и обработок. Запрос из модуля уходит в Консоль запросов, а результат возвращается в диалог.
- **Песочница почти как конфигуратор.** Автодополнение, синтакс-помощник, шаблоны кода, форматирование, режимы языка запросов и СКД.
- **Все, что умеет сервер.** Поиск в интернете, по справке 1С и стандартам разработки, файлы от нейросети и от вас, типовые вопросы; во время хода видно, чем занят сервер.
- **Расходы на виду.** Цена каждого ответа и напоминание пополнить баланс, пока монеты только бесплатные.
- **Доска задач — план, а не список.** Задача раскрывается в шаги, ветка сворачивается, статус задачи складывается из статусов шагов.
- **Ответ печатается по мере генерации** — в том числе когда нейросеть работает инструментами.
- **Субагенты.** Нейросеть поручает шаг задачи субагенту и продолжает с его результатом; видно, кто над чем работает и сколько это стоит.
- **Установщик и автообновление.** Установка на чистую Windows 11, новая версия — по кнопке «Обновить».
- **Надежность.** Автоматические проверки всего, что может испортить модуль, и журнал программы для разбора проблем.
- **Ничего лишнего.** Нет отладочных вкладок; ключ запоминается, только если отмечено «Запомнить ключ».
