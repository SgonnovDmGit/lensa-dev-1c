# Planned

## Next

- **A folder of the AI's own for every configuration.** Queries, exports and drafts the AI writes are kept in a permanent folder of that infobase, and you can view them in the program. The AI moves a query out of 1C text or a module into a separate file, ready for the Query Console.

## Later

- **The full cycle without you.** The model edits a module, checks it with the platform, reads the Messages panel, fixes the errors and saves the module.
- **The model knows where you are working.** It sees the procedure under the cursor, keeps a sandbox for its infobase and remembers plans from other dialogs about that infobase.
- **The right part of the configuration in view.** Find objects by pattern, see the attributes and tabular sections with their properties, and the forms; open the object, manager or form module directly.
- **Creating metadata and working in extensions.** The model creates attributes of complex types, tabular sections, objects and forms, and does the same inside a configuration extension — for example, an extension that blocks shipment when a debt is overdue. It sets breakpoints and starts debugging.
- **What the Query Console and 1C Assistant can do.** Metadata of the live infobase, queries, data, the event log, DCS, building external reports and data processors. A query from a module goes to the Query Console, and the result comes back to the dialog.
- **A sandbox close to the configurator.** Autocompletion, the syntax assistant, code templates, formatting, query language and DCS modes.
- **Development standards.** Search in the 1C development standards.
- **The task board is a plan, not a list.** A task opens into its steps, a branch collapses, and the task status is derived from its steps.
- **Subagents.** The model hands a step of the task to a subagent and continues with its result; you can see who is working on what and what it costs.
- **Removing an extension.** When you ask and confirm, the AI deletes an extension.
- **Reliability.** Automatic checks for everything that could damage a module, and an application log for sorting out problems.
- **Nothing extra.** No debug tabs; the key is remembered only when «Remember key» is checked.
